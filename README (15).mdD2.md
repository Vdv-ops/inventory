# Inventory Tracker               INTERN ID :CITS8444

## Project Overview         

Inventory Tracker is a web-based application developed using Flask and SQLite. It helps users manage products and maintain inventory records efficiently.

## Features

* Add new products
* View all inventory products
* Edit and update product details
* Delete products
* Store product data using SQLite database

## Technologies Used

* Python
* Flask
* SQLite
* HTML
* CSS
